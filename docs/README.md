# srs_app Documentation

This folder contains the working documentation for the iRonda FYP project.

## Key Documents

- `PROJECT_GUIDELINE.md` - main FYP project guideline for scope, development rules, testing, report alignment, and submission readiness.
- `CONTEXT.md` - detailed technical context, implementation notes, architecture, known issues, and backlog.
- `DESIGN.md` - visual design system and UI rules.
- `MILESTONE_PROGRESS.md` - current progress as of 5 September 2026, recorded verification, next milestones, and historical development tracking.
- `SUPER_ADMIN_TEST_REPORT.md` - super-admin feature implementation and verification notes.
- `ACCOUNT_VALIDATION.md` - password, phone and MyKad validation rules, local test coverage and Pi rollout files.
- `RASPBERRY_PI_DEPLOYMENT.md` - current Raspberry Pi migration status, verification evidence and remaining release work.
- `DEVELOPMENT_ENVIRONMENTS.md` - Local XAMPP and Pi launch profiles, server switching and API address configuration.
- `CLOUDFLARE_DATABASE_ACCESS.md` - Windows database connector preparation and remaining private Access/Workbench setup.
- `DIGITALOCEAN_DEPLOYMENT.md` - historical DigitalOcean deployment reference, superseded by the Raspberry Pi plan.
- `ui_layout_analysis.md` - UI layout review notes.

## Usage

Start with `PROJECT_GUIDELINE.md` when planning new work. Use `CONTEXT.md` when technical detail is needed before editing the Flutter app, PHP backend, database, or final report.
